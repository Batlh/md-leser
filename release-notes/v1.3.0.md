**Etappe 3: Editor-Kern**

- Syntax-Hervorhebung für über 30 Sprachen, automatisch nach Dateiendung: Batch, C, C++, C#, CSS, Diff, Go, HTML, INI, Java, JavaScript, JSON, Kotlin, Lua, Makefile, Markdown, PHP, PowerShell, Python, Ruby, Rust, Shell, SQL, TypeScript, XML, YAML …
- Menü „Sprache …“ zum Umstellen von Hand, wie in Notepad++
- Farben passen sich hell/dunkel an
- Kodierung umwandeln: UTF-8, UTF-8-BOM, ANSI
- Zeilenende umwandeln: Windows (CR LF) oder Unix (LF)
- Ansicht: Zeilenumbruch, alle Zeichen anzeigen (Leerzeichen, Tabs, Zeilenenden), Zeilennummern – jeweils ein- und ausschaltbar
- Unter dem Dateinamen steht jetzt Sprache · Kodierung · Zeilenende
