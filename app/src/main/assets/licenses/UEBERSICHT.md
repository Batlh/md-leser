# MD-Leser

Offline-Editor und Markdown-Leser. Quellcode: https://github.com/Batlh/md-leser

Eigener Code: **MIT-Lizenz** (Text unten). Die Funktionen sind Notepad++ nachempfunden, Code aus Notepad++ ist nicht enthalten.

|---|---|---|
| Sora Editor (Editor-Komponente) | LGPL 2.1 | https://github.com/Rosemoe/sora-editor |
| tm4e (TextMate-Engine, in Sora enthalten) | EPL 2.0 | https://github.com/eclipse-tm4e/tm4e |
